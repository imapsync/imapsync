Q. Where can I read up on the various IMAP RFCs?

A. Here:

RFC 9051 - Internet Message Access Protocol (IMAP) - Version 4rev2
https://datatracker.ietf.org/doc/rfc9051/

RFC 2683 - IMAP4 Implementation Recommendations
https://datatracker.ietf.org/doc/rfc2683/


RFC 2595 - Using TLS with IMAP, POP3 and ACAP
https://datatracker.ietf.org/doc/rfc2595/

RFC 5322 - Internet Message Format
https://datatracker.ietf.org/doc/rfc5322/

RFC 2342 - IMAP4 Namespace
https://datatracker.ietf.org/doc/rfc2342/

RFC 2180 - IMAP4 Multi-Accessed Mailbox Practice
https://datatracker.ietf.org/doc/rfc2180/

RFC 4549 - Synchronization Operations for Disconnected IMAP4 Clients
https://datatracker.ietf.org/doc/rfc4549/
