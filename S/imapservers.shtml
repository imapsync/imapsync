Imapsync lists of the Email IMAP providers supported and the IMAP server software applications supported. (back to menu)

To know whether your IMAP server is a widespread choice, take a look at http://openemailsurvey.org/ or the Shodan IMAP query result.
The short answer is that if you're not using the famous Dovecot then you're in a niche!
